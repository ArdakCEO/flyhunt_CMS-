Бесплатная ATS с ИИ: навсегда, а не на 14 дней

Коротко: Flyhunt — ATS, которая бесплатна навсегда для одного рекрутера: вакансии, воронка, база кандидатов и отклики с hh.ru и hh.kz (официальный API HeadHunter) — без карты и без срока. Платится только работа ИИ: проверка резюме с объяснением оценки (20 ₸ за резюме) и поиск кандидатов в вашей базе, на hh и в LinkedIn. Разбор 200 откликов занимает около 15 минут.

Что умеет ИИ во Flyhunt

  • Скрининг откликов: проверяет каждое резюме по критериям вакансии и объясняет оценку — 200 откликов примерно за 15 минут. Подробнее: ИИ-скрининг резюме с hh.
  • Поиск кандидатов в трёх местах: своя база, резюме hh, LinkedIn — включая тех, кто не ищет работу активно.
  • База, которая обновляется сама: сверка с hh и LinkedIn — новое место работы, свежее резюме, контакты.
  • Все отклики в одном списке: hh, LinkedIn, OLX, Astana Hub; размещение вакансии в один клик.
  • ИИ-помощник Қорлан в WhatsApp и в кабинете и MCP-коннектор для Claude и ChatGPT.

Частые вопросы

Есть ли бесплатная ATS с ИИ?

Да. Flyhunt — ATS, которая бесплатна навсегда для одного рекрутера: вакансии, воронка, база кандидатов и отклики hh, без карты и без срока. ИИ-скрининг резюме и поиск оплачиваются по факту токенами: проверка одного резюме — 20 токенов (1 токен = 1 ₸).

Бесплатная ATS с интеграцией hh.ru и hh.kz — какую выбрать?

Flyhunt подключается к аккаунту работодателя HeadHunter через официальный API и бесплатно собирает отклики hh в воронку. ИИ-проверку откликов можно включать по мере необходимости.

Это пробный период?

Нет. ATS бесплатна без ограничения по сроку. Платная часть — только работа ИИ.

Что будет, если токены закончатся?

ATS продолжит работать: вакансии, воронка, база и отклики hh. На паузу встанет только ИИ.

Нужна ли банковская карта для регистрации?

Нет. Регистрация и ATS — без карты; карта нужна только для подключения тарифа.

Можно ли перенести базу из другой ATS или Excel?

Excel загружается самостоятельно за минуту; из других ATS на платном тарифе Flyhunt переносит базу за вас.
